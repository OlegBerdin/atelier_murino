# Ателье в Мурино — демо

Демо-сайт для обзвона: **ателье «Стежок», Мурино**. Папка по схеме `ниша_город`.
Собран из `_templates/catalog-basic`, отличается контентом, палитрой и картинками.
Репозиторий для GitHub Pages: `atelier-murino`.

## Что внутри

- Бренд: **ателье «Стежок»** (вымышленный)
- 6 услуг с ценами: подгонка по фигуре, замена молнии, ремонт джинсов,
  пошив платья, ушить куртку, пошив штор
- Палитра: тёплый беж + терракота (`assets/css/site.css`, `:root`)
- Фото: 6 SVG-заглушек в стиле ткани и стежков
- Телефон, адрес, ИНН, отзывы — **вымышленные**, для демо это нормально

## Локальный просмотр

```powershell
cd "F:\AI_sites\_demos\ателье_мурино"
php -S localhost:8080
```

- сайт: <http://localhost:8080/>
- админка: <http://localhost:8080/admin/> (пароль задаётся при первом запуске на localhost)

> Не открывайте `index.html` двойным кликом: по `file://` браузер не даёт загрузить
> `data.json`, и цены не появятся. Открывайте `http://localhost:8080/` (это делает `preview.cmd`)
> или ссылку GitHub Pages.

## Публикация демо

Имя репозитория — латиницей: `atelier-murino`.

```powershell
cd "F:\AI_sites\_demos\ателье_мурино"
git init
git add .
git commit -m "demo: ателье, Мурино"
git branch -M main
git remote add origin https://github.com/<логин>/atelier-murino.git
git push -u origin main
```

GitHub → Settings → Pages → Deploy from a branch → `main` / root.
Адрес: `https://<логин>.github.io/atelier-murino/`.

Домен `stezhok-murino.ru` в `canonical`, `og:url`, `robots.txt` и `sitemap.xml` —
это будущий адрес клиента. Для демо он не обязателен, менять не нужно.

## Что менять под реального клиента

1. Название ателье и бренд — в `index.html`, `privacy.html`, `send.php`, `data.json`.
2. Телефон, WhatsApp, e-mail, адрес — через админку (вкладка «Контакты»).
3. Цены и услуги — через админку.
4. Фото — загрузить реальные работы через админку или заменить в `assets/img/`.
5. Домен — в `canonical`, `og:url`, `og:image`, `JSON-LD`, `robots.txt`, `sitemap.xml`.
6. Отзывы — только реальные или нейтральные, без названий компаний.
7. ИНН и юридическое название — реальные, в подвале и `privacy.html`.

## Особенности ниши

- Главный страх клиента — «испортят вещь». Поэтому в офферах и на сайте —
  гарантия, примерка и «если не село — поправим бесплатно».
- Ключевые запросы: «ателье Мурино», «подшить брюки Мурино», «заменить молнию Мурино».
- Сезонность: пик — сентябрь–ноябрь (куртки, пуховики) и апрель–май (лёгкая одежда).
- Для обзвона: ателье, ремонт одежды, швейные мастерские, пошив штор.
